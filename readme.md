# SPA "Комментарии"

Тестовое задание: SPA-приложение для добавления и просмотра древовидных комментариев с сортировкой, пагинацией, вложениями и realtime-обновлениями через WebSocket.

## Стек

**Backend**
- Python 3.13, Django 6.1
- Django Ninja (REST API) + Pydantic-схемы
- Django ORM + PostgreSQL
- Django Channels + Daphne (ASGI, WebSocket)
- Redis (channel layer для WebSocket)
- Pillow (обработка изображений)

**Frontend**
- React
- WebSocket-клиент для получения новых комментариев без перезагрузки страницы

**Инфраструктура**
- Docker / Docker Compose (backend, frontend, db, redis, nginx)
- Nginx как reverse proxy перед frontend и backend

## Функциональность

- Добавление комментария с полями: **User Name** (латиница + цифры), **E-mail**, **Home page** (необязательно), **CAPTCHA**, **Text**.
- Ответы на комментарии с каскадным (древовидным) отображением.
- Заглавные комментарии выводятся в виде таблицы с сортировкой по User Name, E-mail и дате добавления (по возрастанию/убыванию). Сортировка по умолчанию — LIFO (новые сверху).
- Пагинация — 25 комментариев на страницу.
- Прикрепление к комментарию картинки (JPG/GIF/PNG, автоматическое пропорциональное сжатие до 320×240) или текстового файла (TXT, до 100 КБ).
- Просмотр вложений с визуальным эффектом (lightbox).
- В тексте комментария разрешены только теги `<a href="" title="">`, `<code>`, `<i>`, `<strong>`; сервер проверяет закрытие тегов и валидность XHTML.
- Панель кнопок для быстрой вставки разрешённых тегов.
- Предпросмотр комментария без перезагрузки страницы.
- Валидация данных на клиенте и на сервере.
- Защита от XSS (санитайзинг через bleach) и SQL-инъекций (использование Django ORM).
- Новые комментарии приходят всем открытым вкладкам в реальном времени через WebSocket.


## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/comments?order_by=...` | Список корневых комментариев с вложенными ответами, пагинация по 25 |
| POST | `/api/comments` | Создание комментария (multipart/form-data, поддерживает `file`) |
| WS | `/ws/comments` | Подписка на новые комментарии в реальном времени |

Допустимые значения `order_by`: `username`, `-username`, `email`, `-email`, `created_at`, `-created_at` (по умолчанию `-created_at`).
